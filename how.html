How We Do It

Using the python libraries DeepFace, cv2, and others in order to scan the faces, then record the user's emotions. After that, the emotions are tracked against a "Password" or sequence of emotions. This allows a more secure and interesting way of protection

01 / INPUT

Find a face

This uses Cv2 and deepface to detect and analyze facial expressions.

→
02 / ANALYSIS

Read expression

The captured facial expressions are analyzed to determine the user's current emotion.

→
03 / PATTERN

Follow the sequence

The detected emotions are then matched against the predefined sequence to verify the user's identity.
